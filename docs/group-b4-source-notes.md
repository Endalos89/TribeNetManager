# Group B batch B4 source notes

B4 follows the current Mandate N02.2 Group B skill table after Scouting:

- Seamanship
- Security
- Shipwright
- Slavery
- Spying
- Tactics
- Torture

Source handling notes:

- The current Mandate skill table is authoritative for the main rollout sequence. Excel valid-skill entries retained for possible future development are not treated as current skill attempts.
- Security is separated clearly from Suppression: Security protects the Clan against Spies/Raiders; Suppression protects the hex against scouting activity including Locate.
- Spying is represented both as a Group B skill and as a scouting mission.
- Shipwright is represented as the actual-worker capacity limit for Shipbuilding, distinct from Shipbuilding skill and Shipyard capacity.
- Torture uses the Mandate's written success formula without inventing a cap. The Dungeon research entry does not state a numeric Torture-skill bonus, so none is invented.
- Research wording that says a chance changes by a percentage is preserved as written rather than silently converting it to a relative or percentage-point interpretation.
