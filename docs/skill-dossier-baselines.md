# Compendium skill dossier baselines

The approved skill pages below are the design baselines for the remaining Compendium skill overhaul.

## Baseline patterns

- **Hunting — efficiency / output.** Use when a skill's value is primarily an output calculation affected by terrain, equipment, support items or other modifiers. Show outputs, factors, implements, maximum benefit and relevant research.
- **Forestry — worker capacity / output.** Use when skill level controls how many workers can be assigned and each worker has a defined output/conversion. Keep the worker cap visually separate from per-worker output and list tools/facilities that change productivity.
- **Woodwork — level unlock / prerequisite.** Use when higher levels unlock recipes or the skill is required alongside other skills. Separate direct recipes from entries where the skill is only one prerequisite, and show the other skill requirements explicitly.
- **Economics — scaling / unlock.** Use when the skill changes a formula or unlocks access at particular levels rather than being a normal worker activity. Show ongoing scaling effects separately from level-specific unlocks.

## Rules for every converted skill

1. Use the pattern that best matches the actual rules; combine patterns where necessary rather than forcing every skill into one layout.
2. Mandate references remain clickable and open the word-for-word source text.
3. Research entries remain linked to the detailed Research List article.
4. Items, materials, buildings and related skills should be clickable whenever a Compendium entity exists.
5. Distinguish worker capacity from per-worker productivity.
6. For crafting skills, distinguish things made directly with that skill from things that merely require the skill as one prerequisite.
7. Prefer the current Mandate N02.2 wording/data over older legacy catalog assumptions.

## Rollout order

Start with **Group A** (resource gathering and general crafting), then Group B, then Group C. The first Group A conversion batch covers Armour, Bonework, Boning, Curing, Dressing and Fletching. Forestry, Hunting and Woodwork are already approved baselines.
