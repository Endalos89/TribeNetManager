# TribeNet Compendium

The Compendium is a Mandate-first reference surface inside TribeNet Manager.

## Initial scope

- Skills index grouped by Mandate skill Groups A, B and C.
- Individual skill articles with full name, short name, group, Mandate section references, summary, limitations, worker limits, stored craft/build recipes and prerequisite links.
- Land Combat and Naval Combat topic articles with cross-links to relevant skills.
- Search across skills, craft/build outputs, recipe inputs and combat topics.
- State restoration so the currently open Compendium article survives application updates/restarts.

## Source policy

`Mandate TN03 rev.N02.1 Feb 26 2026` is the primary source. The Compendium does not replace the Mandate; each article exposes the relevant Mandate section references. Existing structured production data in `mandate-catalog.sqlite` is reused rather than copied into a separate disconnected data store.
