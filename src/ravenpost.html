One-time Google setup

Use the dedicated ravenwake_0485 Gmail account for this connection.

  1. Create or select a Google Cloud project and enable the Gmail API.
  2. Configure the Google Auth consent screen. If the app is in testing, add your Ravenpost Gmail account as a test user.
  3. Create an OAuth Client ID → Desktop app.
  4. Paste the Client ID and Client Secret above, save, then click Connect Gmail.
